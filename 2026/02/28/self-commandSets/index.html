Linux 个人命令库构建

发表于 2026-02-28 分类于 技术
Linux 下，我们通过 shell 命令完成大部分工作，那么是否也可以构建自己的命令 快捷的完成某些我们日常经常要做的一些事情呢？与之前的这篇文章的实现方法类似 Windows 个人快捷启动系统构建，方法是在 Linux 系统下编写 shell 脚本，生成软链接并命令指令，将其放在系统路径下，实现命令可执行配置。具体脚本的编写在 AI 横行的当下并不是难事，重要的是如何构建个人命令系统。下面给我的具体方法。

一、最终效果

  • “?” 指令是个人命令集总览。

  • “LeoSsv” 指令是其中一个自定义指令，当执行指令时会给出命令提示信息。

  • “LeoLoadLog” 指令是其中另一个命令，因为比较简单只做一件固定的事，所以没有帮助信息，直接交互式执行。

二、实现方法

  1. 创建项目路径 🔜 存放所有个人命令集文件，相当于工程目录
  2. 创建系统路径 🔜 用于设置命令名称并使其全局可执行
  3. 创建命令总览文件及其脚本
  4. 添加脚本软连接到系统路径并重命名
  5. 添加说明信息

⏩ 创建项目路径

任意创建一个路径，把其当作个人命令集的项目目录。在里面存放所需的各种文件，主要包括 脚本文件，说明文件，文本文件等。
